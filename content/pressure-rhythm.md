# 압력형 리듬게임

압력 센서를 밟아 플레이하는 리듬게임에 노트 타이밍 자동화 로직을 더한 교내 축제 체험 프로젝트입니다.

## 구현
- `Arduino`와 FSR402 압력 센서로 발판 입력 감지
- Serial 통신으로 센서 값과 임계값을 비교해 압력 여부 판별
- `Unity 2D`와 `C#`으로 노트 이동, 판정, 점수 시스템 구현
- `Python`으로 오디오 진폭 변화량을 분석해 노트 타이밍 자동 생성

## 자동화 방식
일정 구간의 진폭 합 변화량이 큰 시점을 노트 타이밍 후보로 정하고, 변화량 상위 n개만 선택해 난이도를 조절했습니다. 생성한 시간값은 파일로 저장하고 Unity에서 불러와 사용했습니다.
