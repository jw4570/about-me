# Melog

떠오른 멜로디를 빠르게 녹음하고 보관하는 iOS 앱입니다. **Melody + Log**의 합성어로, 로그인 없이 기기 안에서 바로 사용할 수 있는 MVP를 개발하고 있습니다.

## 주요 기능
- 허밍 또는 단선율 멜로디 녹음
- 실시간 음량 파형과 녹음 경과 시간 표시
- 녹음 파일과 메타데이터의 기기 내부 저장
- 폴더, 즐겨찾기, 태그 기반 기록 정리
- 녹음 재생과 편집

## 기술
- `SwiftUI`로 화면 구성
- `AVFoundation`과 `AVAudioRecorder`로 녹음 처리
- `SwiftData`로 녹음 메타데이터 저장
- `Swift Concurrency`로 비동기 작업 관리
