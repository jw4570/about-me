# AI 깊이 맵 기반 적청 입체 영상

단일 2D 영상에서 AI로 깊이 맵을 추정하고, 픽셀별 양안 시차를 적용해 적청 입체 영상을 생성한 실험 프로젝트입니다.

## 접근
- 사전 학습된 `MiDaS` 깊이 추정 모델 활용
- 깊이 맵에서 가까운 픽셀과 먼 픽셀의 이동량을 다르게 계산
- 좌안에는 적색 채널, 우안에는 청색 채널을 적용해 적청 영상 생성
- 프레임 간 깊이 맵 변화에 가중 평균을 적용해 깜빡임 완화
- 깊이 차이를 강조하기 위해 이미지 행렬 원소를 제곱해 조정

## 성능 조정
실시간 깊이 맵 계산이 재생 속도를 따라가지 못해 미리 계산한 깊이 맵을 저장했습니다. `numpy.memmap`으로 필요한 프레임만 디스크에서 불러와 메모리 사용량을 줄였고, 시차 임계값을 재생 중 조절하는 간단한 미디어 플레이어도 구현했습니다.
