# 웹 기반 좌석 선점 키오스크

이동수업 전 좌석 선택 혼잡을 줄이고 출석 확인을 돕기 위해 만든 웹 기반 좌석 선점 시스템입니다.

## 주요 기능
- 학번 입력 후 원하는 좌석 선점
- 이미 선점된 좌석의 재선점 방지
- 동시 요청 시 서버 시간 기준으로 선점 처리
- 관리자용 시간표 편집과 좌석 삭제
- 실시간 출석표 표시와 반별 좌석 행렬 변경

## 기술과 문제 해결
`Flask`, `SQLite`, HTML, CSS, JavaScript로 구축하고 Fly.io에 배포했습니다. 서버가 비활성화된 동안 지정 시각 초기화가 누락되는 문제를 해결하기 위해, 마지막 서버 활성화 시간을 기록하고 다음 접속 시 누락된 초기화 시각을 확인하도록 변경했습니다.
