# 웹 기반 좌석 선점 키오스크

이동수업 전 좌석 선택 혼잡을 줄이고 출석 확인을 돕기 위해 만든 웹 기반 좌석 선점 시스템입니다.

## 주요 기능
- 학번 입력 후 원하는 좌석 선점
- 이미 선점된 좌석의 재선점 방지
- 동시 요청 시 서버 시간 기준으로 선점 처리
- 관리자용 시간표 편집과 좌석 삭제
- 실시간 출석표 표시와 반별 좌석 행렬 변경

## 기술과 문제 해결
`Flask`, `SQLite`, HTML, CSS, JavaScript로 구축하고 Fly.io에 배포했습니다. 서버가 비활성화된 동안 지정 시각 초기화가 누락되는 문제를 해결하기 위해, 마지막 서버 활성화 시간을 기록하고 다음 접속 시 누락된 초기화 시각을 확인하도록 변경했습니다.

| 주제 | 응답 내용 |

| 좌석 확인 | 남은 좌석과 학생 이름을 한눈에 확인할 수 있음 |

### 개선 의견

| 주제 | 응답 내용 |
| --- | --- |
| 좌석 배치 정확도 | 반별 책상 수와 실제 자리 배치가 맞지 않는 경우 개선 필요 |
| 삭제·수정 | 잘못 입력한 좌석을 삭제하거나 수정하는 기능 필요 |
| 이용 안내 | 키오스크 위치, QR·링크, 사용 방법 안내가 더 명확해야 함 |
| 운영 규칙 | 선점 후 실제 착석, 물건으로 자리 맡기기, 대리 출석에 대한 규칙 필요 |
| 접근성 | 이동 중 Wi-Fi, 기기를 가져오지 않은 학생, 키오스크 대기 줄 고려 필요 |
| 이용 시간 | 수업 직전 선점 대신 여러 교시를 미리 선택하는 방식에 대한 의견 |

### 회고

자유좌석제를 선호하는 사람이 더 많을 것이라 예상하고 프로젝트를 진행했지만, 고정좌석제를 선호한 응답도 **14건(41.2%)**으로 생각보다 많았습니다. 기능을 만들기 전에 실제 사용자의 선호와 불편을 먼저 조사했다면, 고정좌석제에서도 편하게 사용할 수 있는 방향까지 더 일찍 고려할 수 있었을 것 같습니다. 다음 프로젝트에서는 구현에 앞서 간단한 선호도 조사와 사용자 의견 수집을 먼저 진행해야겠다고 생각했습니다.

### 개선 방향

- **반별 좌석 배치 커스터마이징**: 반마다 다른 책상 수와 실제 배치 형태를 관리자 화면에서 설정할 수 있도록 해, 화면의 좌석 배치와 교실 환경이 일치하도록 개선합니다.
- **대리 출석과 실제 착석에 대한 운영 설계**: 시스템상 좌석을 선택한 학생과 실제로 앉은 학생이 다를 수 있다는 의견이 있었습니다. 단순히 기능으로만 해결하기보다, 좌석 선점 후 실제 착석 기준과 대리 출석을 막기 위한 운영 규칙을 함께 정해야 합니다.
- **접근성과 이용 흐름 개선**: QR·링크 안내 위치, 이동 시간의 Wi-Fi 환경, 기기가 없는 학생, 키오스크 대기 줄까지 고려해 누구나 같은 조건에서 이용할 수 있도록 UX를 보완합니다.

설문을 통해 좌석 현황을 한눈에 확인하고 이동·자리 맡기기 부담을 줄였다는 긍정 의견을 확인했습니다. 동시에 시스템 도입만으로는 좌석 분쟁이 해결되지 않으므로, **기능 설계와 실제 운영 규칙을 함께 설계해야 한다는 과제**를 확인했습니다.
